# 致敬巨匠 · 36 件作品观展指南

为中国美术馆「致敬巨匠：从达·芬奇到卡拉瓦乔——意大利文艺复兴名作展」制作的移动优先、无构建依赖静态网站。当前版本是**完全本地运行**的独立站点，作品图与 Three.js 运行时均随站点本地部署。

## 内容边界

- 展览基础信息以中国美术馆官方展讯为准。
- 36 张作品图均为已下载到本地、逐件对照展览记录后保留的对应展品图；每件只使用一张，不以同题材、同作者作品或展厅远景代替。
- 作品解读为辅助观展阅读，不替代现场作品标签、图录或学术出版物。

## 本地预览

```bash
npm run dev
```

浏览器打开 `http://localhost:4173`。

不使用 npm 时，也可以执行：

```bash
python3 -m http.server 4173 --directory .
```

## Git 与 Cloudflare Workers Static

- GitHub 仓库：`https://github.com/randaldong/art-expos`
- 生产分支：`main`
- 当前 Cloudflare 项目是 Workers Static 模式；Cloudflare 里 Deploy command 填 `npm run deploy`。
- `npm run deploy` 会先把 `index.html`、`assets/`、`data/` 复制到 `dist/`，再通过 `npx wrangler deploy` 发布 `dist/`。这样不会把 `node_modules/` 或 Wrangler 临时依赖当作静态资源上传，也不依赖 Cloudflare 环境预装 Wrangler。
- Cloudflare 项目连接 GitHub 后，提交并推送到 `main` 会自动触发部署。
- Spaceship 购买的域名可以接入 Cloudflare，不需要中国大陆 ICP 备案；在 Cloudflare 添加站点后，把 Spaceship 后台的 nameserver 改为 Cloudflare 提供的两条 nameserver，然后在 Workers 自定义域名里绑定即可。
- 日常更新流程：

```bash
npm run check
git add <changed-files>
git commit
git push
```

## 快速迭代

```bash
npm run check
```

此检查会确认 36 件作品引用的本地图片文件都存在、路径与文件内容不重复、扩展名与 JPEG 编码一致，并验证前端脚本语法。修改 `assets/styles.css`、`assets/app.js` 或 `data/artworks.js` 后，刷新浏览器即可看到变化。

## 手机预览与交互

- 同一 Wi-Fi 下，手机可打开 `http://<电脑局域网 IP>:4173` 预览；例如当前电脑显示为 `192.168.1.22` 时，打开 `http://192.168.1.22:4173`。
- 已按 `375 / 393 / 430 pt` 三种 iPhone 宽度校验：顶部控制条里的“序厅 / 长廊”、搜索和回看册均保持可见。
- 导航已整合进顶部控制条：手机、平板和桌面统一提供“序厅 / 长廊”两个主入口，搜索与回看册位于同一条控制层。官方三章路线并入长廊页顶部，点击章节会切换下方作品分组；浮层打开时背景失焦，可通过右上角关闭、点击浮层外、`Esc` 或浏览器返回关闭。
- 序厅与长廊是独立页面状态，分别使用 `?page=home`、`?page=collection`；旧的 `?page=route` 会兼容跳到长廊页。搜索与回看册使用 `?panel=search`、`?panel=saved` 表示浮层状态，静态部署时不需要后端路由。
- 作品详情使用 `?artwork=<id>` 进入浏览器历史。iPhone 左滑、系统返回或右上角固定关闭按钮都会关闭详情，并恢复进入作品前的长廊筛选和滚动位置。
- 回看册存储在浏览器的 `localStorage`：刷新、关闭后再次打开同一网址仍会保留；清除 Safari 网站数据或更换设备后才会消失。

## 视觉方向

- 整体采用“夜间展厅 × 纸本长廊”的视觉概念：序厅保持深酒红暗室氛围，长廊使用羊皮纸阅读底色，暖金属高光和悬浮玻璃控制层贯穿两端。
- 首页首幅作品由本地 Three.js 驱动：画框是带厚度、背板、支撑结构与连续倒角金属边的真实 3D 物体，支持鼠标与触控任意方向 360° 旋转、惯性和停留；点击画框进入当前作品详情。
- “邂逅一幅”会在首页原地更换 3D 画框中的作品并同步更新展签，不再跳入无法从导航抵达的独立页面；新作品会沿最短路径转回正面。
- 作品墙通过不同画框颜色与柔和阴影模拟展墙；宽屏使用严格同高同基线的四列网格，避免艺术化错位影响快速浏览，列表和正文仍优先保证稳定、清晰和可读。
- 官方动线与观展步骤使用滚入显影，作品列表、搜索结果和正文不使用延迟隐藏，避免产生“内容未加载”的错觉。
- 系统开启“减少动态效果”时，会自动关闭入场动画；WebGL 不可用时首页自动回退到 CSS 画框。

## 目录

- `index.html`：页面结构
- `assets/styles.css`：移动优先样式
- `assets/app.js`：筛选、搜索、回看册与详情交互
- `assets/hero3d.js`：首页 Three.js 画框、自由旋转、惯性与换画
- `assets/vendor/three.module.js`：随站点本地部署的 Three.js 模块，不依赖外部 CDN

- `assets/artworks/`：36 张本地展品图片，约 18 MB
- `data/artworks.js`：36 件作品、章节和艺术家资料
- `data/curatorial-notes.js`：画家档案、作品细读、问答与研究背景

## 作品阅读结构

每件作品按更接近美术馆讲解牌的顺序展开：

1. **先认识画家**：姓名、年代、活动地点与一句有用的创作特征。
2. **再看作品**：标题与题材、媒材、年代等小档案。
3. **画面里发生了什么**：明确说出人物、动作、物件与叙事，不只写气氛。
4. **画面细读**：指出从哪里开始看、细节如何支持解读。
5. **故事底本与时代**：补足圣经、古希腊神话、历史事件、宫廷委托或真实人物的背景；无法确定的地方会明说。
6. **画法与材质**：解释线条、光线、色彩或构图的具体做法。
7. **画中暗号**：每件至少三条细节卡，明确标注为「画面可见」「常见解读」或「仍有讨论」，避免把推测写成事实。
8. **它为何重要**：用艺术史位置、评论焦点或归属争议解释作品为什么值得在这 36 件里停下来。
9. **作品来历与研究**：交代可核对的年代、收藏、委托和研究背景。
10. **画前问题 / 参考答案**：问题不悬空，答案会说明依据。
11. **继续认识画家**：在末尾提供更完整的艺术家介绍。

## 资料依据

导览内容以中国美术馆的展览官方条目、乌菲齐美术馆的公开馆藏资料为主要依据；涉及佛罗伦萨女性侧面肖像的社会背景，参考大都会艺术博物馆相关馆藏说明。对仍有归属、人物身份或图像版本争议的作品，正文保留“通常认为”“有研究讨论”“以现场作品标签为准”等表述，不把推测写成定论。

## 展厅路线

网站采用中国美术馆公布的三章结构，而非按作品编号硬切：

1. **人文曙光——佛罗伦萨与文艺复兴**：15 件
2. **群星璀璨——拉斐尔和16世纪意大利绘画**：9 件
3. **光色交响——威尼斯画派和卡拉瓦乔**：12 件

全览和章节筛选都会按这条现场路线排序。
